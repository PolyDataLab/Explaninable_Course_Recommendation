# Explainable_Course_Recommendation
This repository contains the dataset and implementation methods used in the following paper:
Khan, M. A. Z., Luo, D., & Polyzou, A. (2025, October). **Reasoning with Knowledge Graphs for Trustworthy Course Recommendation.** In 2025 IEEE 12th International Conference on Data Science and Advanced Analytics (DSAA) (pp. 1-10). IEEE.
